# Minor_project_1

## WhatsApp Group Chat Analyzer

A Python-based WhatsApp group chat analyzer that analyzes messages, participant activity, top words, busiest days and hours, response patterns, silent streaks, and personality archetypes.

## Features

- Chat parsing
- Group overview
- Messages per person
- Busiest day and hour
- Activity heatmap
- Top words
- Response speed and silent streaks
- Personality archetype detection
- Final formatted report

## Technologies Used

- Python
- NumPy
- Datetime
- File handling
- Basic Python data structures

## Dataset

The project analyzes the provided WhatsApp chat file `hostel_bois.txt`.

## Project Output

The analyzer generates a complete report containing group statistics, activity patterns, response behavior, and personality archetypes.
